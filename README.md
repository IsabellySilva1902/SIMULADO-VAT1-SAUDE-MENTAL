# Simulado VAT1 - Saude Mental

Simulado interativo de multipla escolha (estilo ENAMED) cobrindo as 7 aulas da disciplina de Saude Mental (UNEXMED): Introducao a Saude Mental, Delirium, Esquizofrenia, TEA, TDAH, Transtornos Alimentares e Transtornos do Sono-Vigilia.

O app inteiro esta em [`index.html`](index.html) - um unico arquivo HTML autossuficiente (Tailwind CSS via CDN), sem backend.

## Como testar

- **Pelo navegador (recomendado):** ative o GitHub Pages deste repositorio (Settings > Pages > Branch: escolha a branch desejada > pasta `/ (root)`) e acesse a URL gerada pelo GitHub - funciona em celular, tablet e computador.
- **Localmente:** baixe `index.html` e abra direto no navegador.
